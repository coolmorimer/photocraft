PhotoCraft RU — независимая русская сборка coolmorimer
Основана на PhotoCraft команды ArtCraft. Это не официальный выпуск ArtCraft.

УСТАНОВКА
Запустите установщик. Права администратора не нужны.
Оригинальный PhotoCraft можно оставить установленным рядом.
Русская сборка использует отдельную папку настроек PhotoCraft-RU.

УДАЛЕНИЕ ФОНА — ЛОКАЛЬНО
1. Откройте «Фильтр → ИИ-инструменты → Установить модель удаления фона».
   Один раз потребуется интернет и около 5 МБ на диске.
2. Выберите пиксельный слой и команду «Удалить фон с помощью ИИ».
3. Результат — маска слоя. Исходные пиксели сохраняются.
   Маску можно поправить кистью. Операцию можно отменить.
Дискретная видеокарта не требуется. Сложные края могут потребовать ручной правки.

ГЕНЕРАЦИЯ — ЧЕРЕЗ ВАШ API
1. «Фильтр → ИИ-инструменты → Настроить API генерации».
2. Выберите протокол: OpenAI-совместимый Images Edits, OpenRouter Images
   или Google Gemini. Можно изменить полный адрес API и название модели.
   Модель должна поддерживать редактирование изображений, а не только текст.
3. Вставьте свой API-ключ. По желанию сохраните его в хранилище ключей ОС.
   Без сохранения ключ действует только до закрытия редактора.
4. Выделите область, откройте «Правка → Генеративная заливка».
5. Введите описание результата. Перед отправкой видны адрес API и модель.
6. Результат появится отдельным слоем внутри исходного выделения.
   Оригинал сохраняется. Обычная команда «Отменить» удаляет результат.

ЧТО ОТПРАВЛЯЕТСЯ
Только при запуске генеративной заливки выбранному API отправляются описание,
выделенная область с небольшим контекстом и маска. Контекст ограничен
1024 пикселями по длинной стороне. Весь документ и остальные слои не отправляются.
Удаление фона и остальные инструменты остаются локальными.
Ключ не записывается в документы, историю или обычный файл настроек.
«Удалить сохранённый ключ» удаляет ключ текущего подключения.
При смене адреса или модели укажите ключ для нового подключения.

ОПЛАТА И СОВМЕСТИМОСТЬ
Оплата, скорость, качество и лимиты определяются выбранным провайдером.
Отмена останавливает ожидание редактора, но сервис может продолжить работу
и списать средства за уже начатый запрос. Автоматических повторных запросов нет.
Не каждый API совместим с перечисленными протоколами. Произвольные SDK,
асинхронные очереди и нестандартные API требуют отдельного адаптера.
Для удалённых сервисов используется HTTPS. HTTP разрешён только для localhost.
При недоступном хранилище ключей ОС используйте ключ без сохранения.

ЛИЦЕНЗИИ
Редактор: MIT OR Apache-2.0; авторство исходного проекта сохранено.
U²-Net: Apache-2.0. Модель u2netp загружается отдельно из выпуска rembg.
Веса генеративных моделей и локальный генератор в установщик не входят.

Исходники и выпуски: https://github.com/coolmorimer/photocraft
